Panduan Menghubungkan ke Ponzi15

          
Hanya perlu 1 langkah untuk menggantikan API bawaan dengan API Vercel ini

        

      


      

        

          
1

          
Deploy ke Vercel

          
Push folder /apics ini ke GitHub atau jalankan perintah vercel deploy di terminal folder apics/.

        


        

          
2

          
Salin URL API Vercel Anda

          
Setelah deploy, Anda akan mendapatkan domain Vercel. Contoh:

          

            https://projek-anda.vercel.app/api
            
          

        


        

          
3

          
Masukkan ke Ponzi15

          
Di database Ponzi15 (tabel settings, kolom payment_api_base) atau di menu Admin Pengaturan Web, ubah menjadi URL Vercel di atas.
